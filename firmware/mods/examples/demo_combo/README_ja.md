# demo_combo

Open-Meteo から長久手市の天気予報を HTTPS で取得してしゃべるひな形 MOD です。

通信は `device.network.https` を使います（`fetch` は使いません）。
ステータス／診断以外は基本的に発話し、見回し・うなずき・首振りを行います。

## 動作

起動直後に `版:speak-motion-1` と出れば最新です。

- 起動時に挨拶してから、約8秒後に初回天気を取得します
- その後は2時間おきに自動取得・発話します
- 座標は長久手市役所付近です
- 空き時間は見回し動作をします

| 操作 | 動作 |
| --- | --- |
| （自動） | 発話＋動作しながら HTTPS で天気取得 |
| ドロワー「天気」 | 手動で同じ取得を実行 |
| ドロワー「診断」 | ステータス吹き出しのみ（発話なし） |

## インストール
