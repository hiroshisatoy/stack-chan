# demo_combo

Open-Meteo から長久手市の天気予報を HTTPS で取得してしゃべるひな形 MOD です。

通信は `device.network.https` を使います（`fetch` は使いません）。

## 動作

起動直後に `版:nagakute-2h-1` と出れば最新です。

- 起動約5秒後に1回取得し、その後2時間おきに自動取得・発話します
- 座標は長久手市役所付近（北緯35.18411 / 東経137.04872）です

| 操作 | 動作 |
| --- | --- |
| （自動） | HTTPS で天気取得 → 成功なら発話 |
| ドロワー「天気」 | 手動で同じ取得を実行 |
| ドロワー「診断」 | Wi-Fi / HTTPS クライアント有無と設定確認 |

## インストール

Gallery から入れ直してください。
