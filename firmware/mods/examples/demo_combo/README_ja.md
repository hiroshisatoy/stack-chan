# demo_combo

Open-Meteo から長久手市の天気予報を HTTPS で取得してしゃべるひな形 MOD です。

吹き出しには読みやすい日本語（漢字あり）を出し、声は `stackchan-voice` 向けのひらがなで読みます。

## 動作

起動直後に `版:kana-balloon-1` と出れば最新です。

- 起動時に挨拶 → 初回天気取得 → その後2時間おき
- 空き時間は見回し動作

| 操作 | 動作 |
| --- | --- |
| （自動） | ふきだし（漢字）＋ひらがな発話で天気をお知らせ |
| ドロワー「天気」 | 手動で同じ取得を実行 |
| ドロワー「診断」 | ステータス吹き出しのみ |

## インストール

Gallery から入れ直してください。
